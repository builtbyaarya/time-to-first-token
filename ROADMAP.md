# Roadmap

## Shipped

- 1.0 (24 Oct 2026): the planner, the 3D build with one fixed sun and a section view, the critical-path schedule, levers, capex and opex, risk register, stress tests, CSV and JSON export, the emailed feasibility study, the data pack with 200-odd sourced values.

## Next pieces

1. Per-ISO large-load timelines for PJM, MISO and SPP from the operators' own large-load process documents, replacing the US default where the pack still uses it.
2. Metro cost indices for Northern Virginia, Phoenix, Dallas, Atlanta and Columbus once a public index covers them.
3. Phased energization: a utility ramp schedule (for example Dominion's five-year ramp) against a phased rack install, with first token on the first tranche.
4. A share card: a still render of the finished site with the headline numbers, like the sibling game's result card.
5. Weekly refresh of the time-sensitive values (EIA state prices, Henry Hub, the ERCOT batch figures) by the scheduled job, with a dated changelog line.
